# insurance_cost_prediction
Machine Learning project for predicting medical insurance costs using Python, EDA, feature engineering, regression models, and Scikit-learn.

## Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Regression Model Training
- Model Comparison & Evaluation
- Hyperparameter Tuning
- Insurance Cost Prediction

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Models
- Linear Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Dataset
The dataset contains customer demographic and health-related information, with `charges` as the target variable.
